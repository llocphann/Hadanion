## Current implemented source (do not rebuild)

- **Chat + model reuse:** `services/WullMind.qml` uses `Ai.createTextSession`, Hadalis's AI model catalog and the existing optional local GGUF/Ollama helper. Explicit chat and Mood/Energy check-ins have existing separate UI; history is bounded SQLite/WAL (max ~2,000 records, paged), not a long-term memory engine. Existing Companion config key `abyss.companionMind`, `wull` IPC and privacy/default-off behavior stay compatible.
- **Persona:** [`services/WullPersona.js`](../../services/WullPersona.js) and [`scripts/wull/persona.py`](../../scripts/wull/persona.py) now provide compact *different* Aqua and Octo voices with shared bounded `text+expression` rules. QML/shared session and local helper are wired to them. [JS](../../scripts/test-wull-persona.cjs) and [Python](../../scripts/test-wull-local-persona.py) assertions are offline; output quality on selected models remains unverified.
- **Reply boundaries:** [`WullReplyGuard.js`](../../services/WullReplyGuard.js) and [`reply_guard.py`](../../scripts/wull/reply_guard.py) reject internal protocol tokens and bound output; malformed structured responses cannot be passed through as plain text. They are not full prompt-injection protection and require actual model/host QA for all routes.
- **Voice evaluation:** [aggregate-only evaluator](../../scripts/wull-companion-voice-eval.py), [14 synthetic matched Aqua/Octo prompts](../../scripts/fixtures/hadanion-voice-scenarios.json) and [fixture test](../../scripts/test-wull-companion-voice-eval.py). This tooling never calls a model, copies user chat or asserts persona parity without live response evidence.
- **Dormant opt-in scaffolds:** [consent-only SQLite memory prototype](../../scripts/wull/memory_store.py) (source tag, scope `shared|aqua|octo`, inspect/forget/expiry) and [fake-clock proactive policy](../../scripts/wull-proactive-policy-prototype.js) (opt-in, quiet hours, DND/fullscreen/manual, cooldown/ignored streak) plus offline tests. **NEITHER is connected to live QML, installed state or background inference.** A prototype is not a delivered feature.
- **Source CI receipt:** [GitHub Actions #37821769236](https://github.com/llocphann/Hadanion/actions/runs/37821769236) **PASS** on exact Hadanion `main@a456991ba56b5c97e5354c782ae8d592a4dc13d0`: Python/Node contracts, QML syntax and independent QSB shader builds. No full `make test HADALIS_ROOT=...`, real-model EN/VN evaluation or GPU/host acceptance is established by this.
- **AI independence:** Aqua/Octo movement/expressions and optional deterministic cowork must remain useful with AI disabled, slow, missing or canceled. Text proposed by a model never authorizes a desktop action or overwrites a preference on its own.
